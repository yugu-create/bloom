1. プロジェクト概要・コンセプト設定
--------------------------------------------------------------------------------
■ ブランドステートメント
「キレイになる。自信がつく。未来が楽しみになる。」
「人生を、もっと私らしく。」

■ 事業概要・コンセプト
 Bloom Life Studio は、従来の美容サロンの枠を超え、女性の人生をトータルでサポートする
「ライフスタイルサロン」です。単なる外見のケアにとどまらず、美容・健康・学び・交流・お金の
 5つの側面から女性の自分らしい生き方と自己実現を多角的にバックアップします。

■ 企画目的
 1. ブランド認知の拡大と世界観（上質感・親しみやすさ・癒やし）の確立
 2. 新規顧客（無料カウンセリングおよびサービス予約）の獲得（LINE予約への集約）
 3. 単発施術にとどまらない、イベント・セミナー・ギフト等のクロスセルによるLTVの向上
 4. モバイルユーザーを意識したスムーズな予約・お問い合わせ体験の提供

■ ターゲットペルソナ
 ・メイン層：30代〜50代の女性（働く女性、主婦、キャリアやライフスタイルの転換期にいる女性）
 ・ニーズ：
   - 自分に似合うメイクやファッション（パーソナルカラー・顔タイプ）を知りたい
   - 日常の疲れを癒やしたい（ヘッドスパ・セルフケア）
   - 将来のお金や新NISAについて分かりやすく学びたい
   - 同じ価値観を持つ女性同士で気軽につながれるコミュニティ（お茶会・交流会）を探している
   - 大切な人や自分へのご褒美にセンスの良いギフトを贈りたい

2. サイト構造・情報設計（サイトマップ）
--------------------------------------------------------------------------------
本WEBサイトは、トップページ（1ページ完結型LP＋セクション遷移）と、動的JavaScriptによる
詳細ページ（イベント詳細・ギフト詳細）で構成されています。

■ サイトマップ構造
 [TOPページ] index.html
  ├── HERO（メインビジュアル・キャッチコピー・予約CTA）
  ├── ABOUT US（私たちについて・ブランド理念・5つのサポート軸）
  ├── SERVICE（サービス一覧：パーソナルカラー、顔タイプ、メイク、ヘッドスパ、健康、マネー）
  ├── QUAD SECTION（4複合セクション）
  │    ├── GIFT SELECTION（ギフトおすすめ・詳細遷移）
  │    ├── EVENT & SEMINAR（イベント・セミナー一覧・詳細遷移）
  │    ├── VOICE（お客様の声）
  │    └── INSTAGRAM（SNS連携・ギャラリー）
  ├── CTA BAND（コンバージョン誘引バンド）
  └── FOOTER / ACCESS（店舗情報・アクセス・フッターナビ・SNS）

 [詳細ページ]
  ├── ギフト詳細ページ (gift-detail.html?id=X)
  │    ├── パンくずリスト
  │    ├── メインギャラリー＆サムネイル切替（アロマキャンドル、ブーケ、ケアセット等）
  │    ├── 商品スペック・特徴・おすすめポイント
  │    ├── アクション（LINE問い合わせ・電話予約）
  │    ├── ギフト詳細説明文
  │    └── 関連ギフト一覧
  │
  └── イベント詳細ページ (event-detail.html?id=X)
       ├── パンくずリスト
       ├── メインギャラリー＆サムネイル切替（メイクレッスン、姿勢改善、NISA講座等）
       ├── 開催概要（日時、定員、参加費、持ち物、会場）
       ├── アクション（LINE申し込み・電話申し込み）
       ├── イベント詳細説明文
       └── 他のイベント・セミナー一覧

3. デザインコンセプト・トーン＆マナー（Visual Design Specification）
--------------------------------------------------------------------------------
■ トーン＆マナーキーワード
 「温かみ」「洗練」「ナチュラル」「品格」「やわらかさ」「信頼感」

■ カラーパレット（Color Scheme）
 落ち着いたオーガニックトーンと上品なローズ・ゴールドを組み合わせ、大人の女性が居心地良く
 感じるカラーリングを採用。
 ------------------------------------------------------------------------------
  カラー種別         カラーコード    用途・ビジュアル意図
 ------------------------------------------------------------------------------
  メインベース       #FBF6F1 (Cream)      背景全体。温かみと柔らかさを演出
  サブベース         #F4EAE1 (Cream Deep) セクション背景（About / Quad）。メリハリを付与
  メインローズ       #B15D68 (Rose Deep)  主要CTAボタン、ハイライト、強調文字、アイコン
  サブローズ         #C97B84 (Rose)       アクセント、hover時の変化

  サブテキスト       #6B5A56 (Ink Soft)   補足説明、キャプション、英字サブタイトル
  フッター背景       #2E2422 (Dark Ink)   全体を引き締めるダークブラウン
 ------------------------------------------------------------------------------

■ タイポグラフィ（Typography）
 明朝体とゴシック体を役割に応じて使い分け、凛とした上質感と視認性の高さを両立。
 ・見出し・ブランドロゴ：'Shippori Mincho'（しっぽり明朝）
   - 和の情緒と洋のエレガンスを兼ね備えた明朝体。美しい和文見出しを実現。
 ・本文・UI要素・英数字：'Noto Sans JP', sans-serif
   - 可読性と普遍性に優れた標準ゴシック体。スマホ画面でも視認性を確保。

■ ビジュアル・レイアウト表現
 ・角丸（border-radius: 4px〜8px, ボタンは完全カプセル型 999px）で親しみやすさを付与。
 ・ドロップシャドウは低彩度・深めのぼかし（`rgba(58,46,44,.3)` 等）を使用し、立体感と重厚感を演出。
 ・ヒーローセクションには、キービジュアル画像の横でゆっくり回転する丸型バッジ（CSS Keyframe Animation）を配置し、視線を惹きつける動的アクセントを追加。

4. 各主要セクションの機能・コンテンツ仕様要件
--------------------------------------------------------------------------------
[1] ヘッダー (Header)
 ・追従型（sticky）ヘッダーとし、スクロール時にJavaScriptで影（box-shadow）を付与。
 ・ロゴマーク（イニシャル'B'のサークルロゴ＋英文表記）。
 ・主要ナビゲーション（和英併記：HOME / ABOUT / SERVICE / GIFT / EVENT / VOICE / ACCESS）。
 ・直感的な電話番号・受付時間表示と、高コンバージョン率を狙う「LINEで予約する」ボタン。
 ・レスポンシブ（1080px以下）でバーガーメニューに自動切り替え。

[2] ヒーローセクション (Hero Section)
 ・2カラムグリッド構成（左：キャッチコピー＋リード文＋Wボタン、右：ビジュアル＋アニメーションバッジ）。
 ・メインCTA：「LINEで予約する」（ローズディープの塗りつぶし＋シャドウ）。
 ・サブCTA：「無料カウンセリング予約」（スタイリッシュな枠線ボタン）。

[3] 私たちについて (About Section)
 ・サロンの雰囲気（店内写真）と理念文を配置。
 ・「5つのサポート」カードグリッド：
   1. BEAUTY（美容）   : 外見の魅力を引き出し自信を育てる
   2. HEALTH（健康）   : 心と身体を整え健やかな毎日へ
   3. LEARNING（学び） : 学びで視野を広げ人生を豊かに
   4. COMMUNITY（交流）: つながりが毎日を彩る
   5. FINANCE（お金）  : 将来の安心をつくり理想の人生をデザイン
   - マウスホバー時にふわっと浮き上がるマイクロインタラクション（`transform: translateY(-6px)`）を導入。

[4] サービス (Service Section)
 ・提供メニュー6種をカード型ギャラリーで表示。
   （パーソナルカラー診断 / 顔タイプ診断 / メイクレッスン / ヘッドスパ / 健康サポート / マネー相談）
 ・カードホバー時に画像が拡大（`transform: scale(1.06)`）する視覚効果。

[5] クアッド・多角情報セクション (Quad Section)
 4つの重要コンテンツを横並び/2×2グリッドで効率的に配置。
 ① GIFT SELECTION : 画像4点の2列グリッド＋詳細リンク
 ② EVENT & SEMINAR: サムネイル付きイベントリスト＋タグ（BEAUTY, HEALTH, FINANCE, COMMUNITY）
 ③ VOICE          : 5つ星評価付きのリアルな口コミカード
 ④ INSTAGRAM      : 正方形画像6点のSNSギャラリー

[6] CTAバンド (CTA Band)
 ・グラデーション背景（`linear-gradient(120deg, #B15D68, #96444f)`）と光の円弧パターン。
 ・「あなたらしい人生を、もっと楽しみませんか？」のメッセージで離脱前に最後のコンバージョンを促す。

[7] 詳細ページ（動的シングルページ構成 / Dynamic Detail Pages）
 ・URLパラメータ（`?id=1`〜`4`）を取得し、JavaScriptオブジェクト（`GIFTS` / `EVENTS`）から該当データを動的レンダリング。
 ・存在しないIDの場合は404風の「見つかりませんでした」メッセージと戻るボタンを表示。
 ・画像ギャラリー機能：サムネイルクリックでメイン画像を即座に切り替え。
 ・関連コンテンツ表示：閲覧中以外のアイテムを自動抽出して下部にカード表示。

5. テクニカル・レスポンシブ・UI仕様
--------------------------------------------------------------------------------
■ ブレイクポイント要件
 ・PC / デスクトップ：1200px〜（最大コンテンツ幅 1200px / ヘッダー 1300px）
 ・タブレット / 小型PC：1080px以下
   - メインナビゲーションを非表示にし、ハンバーガーメニューへ切替。
   - 2カラムレイアウト（Hero, About）を1カラム縦並びに再配置。
   - Quadセクションを2×2グリッドへ変更。
 ・スマートフォン：640px以下
   - パディングを20pxに調整。
   - サービス・Quad・関連カードを1〜2カラム化。
   - ボタン類をフルサイズ（縦並びタップしやすい形状）へ最適化。

■ フロントエンド技術要件
 ・HTML5 / CSS3（CSS Custom Properties / Variables 活用による保守性確保）
 ・Web Fonts: Google Fonts (Shippori Mincho, Noto Sans JP)
 ・Pure JavaScript (ES6+):
   - URLSearchParamsによる動的データ表示
   - イベントリスナーによる画像ギャラリー切替・スクロール検知
   - ページ内スムーズスクロール機能 (`scrollIntoView`)

6. コンバージョン戦略・運用展開案
--------------------------------------------------------------------------------
1. LINE公式アカウント連携への集約
   - 問い合わせ・予約の障壁を下げるため、電話よりもLINE予約をメインCTAとして設計。
   - 無料カウンセリングを設けることで、最初の一歩を踏み出させやすくする。

2. イベント・ギフトによる新規顧客流入・再来店促進
   - メイクやNISAなどの魅力的なテーマでイベントを開催し、新規顧客の接点を創出。
   - サロンオリジナルギフトの展開により、既存客のギフト需要やブランドファン化を促進。

3. SNS（Instagram）との相乗効果
   - 診断ビフォーアフターやサロンの日常、イベント風景をInstagramに投稿し、WEBサイト上のギャラリーでリアルタイムな世界観を補強。
